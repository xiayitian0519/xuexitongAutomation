# 当前题页执行与恢复

此执行器独立于旧课程总控。只处理已明确授权的一份任务，不能因为安装成功自动扫描或执行全部课程。页面结构存在边界，离线通过不代表所有真实页面兼容。

## 接入

1. 先按根目录说明安装并建立专用Edge持有进程。本人进入任务并完成安全验证，助手重读任务身份和状态后接手；不自行点开始。
2. 状态：`node automation/session-owner.mjs --status`。派发格式：`node automation/existing-session.mjs automation/实际操作模块.mjs 稳定任务编号`。其中“实际操作模块.mjs”须替换为本轮已创建并检查过的操作模块，并非包内现成任务；模块须位于本项目automation或.tmp内，导出 `default async function(session)`。稳定编号用于去重，结果未知不能换编号盲目重发。
3. `session` 提供现有专用浏览器、context及page；通过 `context.pages()`核对当前题页，不创建替代浏览器或使用系统输入。操作模块必须把 `session.signal` 传入 `runExam`、fetch及模型请求，以便停止时取消后续动作。未配合取消的操作会记为 `stop-unconfirmed`，不能因此声称已停。诊断只输出数量、安全状态和不带查询参数的页面信息。
4. 模块可导入 `runExam`，参数为 `{page,identity,directory,minimumMinutes,deadline,listening,...}`。身份必须来自实际平台并核对，directory位于 `.automation.local/exams/`，不能复用他人的任务标识。
5. 最新材料版本为 `2026-11-17-material-recovery-v1`。长驻进程加载 `exam-runner.mjs?material-recovery-v1`，核对导出revision；修改磁盘代码不等于旧进程已热更新。

包内已有 `automation/session-inspect.mjs`，可供安装后的只读连接检查派发：只返回连接、页面数量与去掉查询参数的页面位置，不打开页面、不输入内容、不调用模型。实际任务操作模块仍需按本轮授权创建；连接检查通过不等于作业已开始或完成。

## 处理与保护

1. 只支持已适配的整卷预览页面、选项和已知编辑器。未知分页、特殊控件、计算大题、手写/上传/论文暂缓，不凭栏目名猜实际要求。
2. 题图按共享材料、问句和选项对应；多音频按明确段号和页面顺序关联，保留每段问句编号。不完整材料在付费前暂停。
3. 默认每张图5秒、每题卡15秒截图预算，不循环重试。已识别内容哈希原图可经校验缓存恢复；隐藏、动画、源或样式变化时不错误复用。
4. 先持久化模型回包，后校验。完整有效结果本地恢复，部分无效保留有效项和异常题号并整组暂缓。未知结果不重发，不删检查点、不改试卷指纹。
5. 填写后保存、刷新逐题回读，满足平台限制后才在授权范围内提交。结果不明不重复提交；平台成功后先通知，再归档。
6. 私有材料、回包、缓存、账本和完成记录留在 `.automation.local/`。不得分享真实题目、带签名URL或凭证，不通过删历史解除保护。

验收：`node tests/verify-exam-material-recovery.mjs`。默认不运行会创建Edge的旧全套测试。首次真实连接、CLI登录、页面适配和实际任务结果分别记录。
